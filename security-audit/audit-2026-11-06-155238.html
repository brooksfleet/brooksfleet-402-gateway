Framework-specific findings

Next.js 16.4.0 was affected by two critical unauthenticated RCE advisories (GHSA-2464-fhr4-w9xw, GHSA-673q-mjm6-r5xr) and a high DoS (GHSA-p3m5-59mp-jv5r), all fixed in 16.4.1. The project now develops on 16.4.5.

Next.js is an optional peer here, so the exposure is on consumers: the 0.1.3 peer range next >=16.2.6 allows vulnerable versions. The floor is now >=16.4.1, which reaches consumers only with a new release.

React 19.3.1 meets the 18.3 minimum. Express resolves body-parser 2.4.0, which clears GHSA-27r3-jxmh-p828.
